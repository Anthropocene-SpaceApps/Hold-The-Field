# Use of AI

Space Apps requires every AI tool to be named, with what it did and the data it worked on.

| Tool | Used for | Data it worked on | Reviewed by |
|---|---|---|---|
| Claude (Anthropic) | Planning, PRD, starter code scaffold, script drafting | Our own notes and public NASA POWER documentation | Team |
| Claude Code (Anthropic) | Wrote the Java/LWJGL game in `game/`: simulation port, procedural 3D renderer and GLSL shaders, UI, launcher, saves, tests; extended the synthetic sample dataset to start on 1 Dec 2016 | This repository and the public NASA POWER API documentation. It could not reach the NASA API, so it fetched no real data | Team (please review before submission) |
| _add every other tool_ | | | |

No AI-generated content is presented as real data. The sample dataset (`data/haor-2017.json`) is synthetic, including the December 2016 days added for the planting-date choice, and is labelled as such in the game until it is replaced by real NASA POWER data (launcher > NASA Data > Update NASA data). All textures, 3D models and sounds in the game are generated by code; no third-party art or audio is used. Font: DejaVu Sans (free licence, `game/src/main/resources/fonts/DEJAVU_LICENSE.txt`).
