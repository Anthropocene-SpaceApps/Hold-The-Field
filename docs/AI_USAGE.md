# Use of AI

Space Apps requires every AI tool to be named, with what it did and the data it worked on.

| Tool | Used for | Data it worked on | Reviewed by |
|---|---|---|---|
| Claude (Anthropic) | Planning, PRD, starter code scaffold, script drafting | Our own notes and public NASA POWER documentation | Team |
| Claude Code (Anthropic) | Wrote the Java/LWJGL game in `game/`: simulation port, procedural 3D renderer and GLSL shaders, UI, launcher, saves, tests; extended the synthetic sample dataset to start on 1 Dec 2016 | This repository and the public NASA POWER API documentation. It could not reach the NASA API, so it fetched no real data | Team (please review before submission) |
| Claude Code (Anthropic), second round | Bengali interface (text shaping with the JDK and the translations in `lang/bn.txt`), the Barind drought scenario (engine, scoring, scene look, tests), Linux/Windows/macOS packaging and the release workflow, the launcher/app icon art | This repository. The Barind sample data is synthetic | Team. **The Bengali text needs review by a native speaker** |
| _add every other tool_ | | | |

No AI-generated content is presented as real data. The bundled `data/haor-2017.json` and `data/barind-2010.json` files are real NASA POWER snapshots; the flood date and drought thresholds are modelled simplifications documented in `docs/DATA.md`. All textures, 3D models and sounds in the game are generated by code; no third-party art or audio is used. Fonts: DejaVu Sans (free licence, `game/src/main/resources/fonts/DEJAVU_LICENSE.txt`) and Noto Sans Bengali (SIL Open Font License, `game/src/main/resources/fonts/NOTO_BENGALI_LICENSE.txt`, taken from the `@fontsource/noto-sans-bengali` npm package and converted from WOFF to TTF). The app icon in `packaging/icons/` is drawn by a script.
